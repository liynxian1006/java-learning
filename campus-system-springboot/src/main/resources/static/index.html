接口清单

GET /student/list查询全部学生
GET /student/{id}按 id 查询学生
POST /student/add新增学生
PUT /student/update修改学生
DELETE /student/{id}删除学生
GET /job/list查询全部岗位
GET /job/page?page=1&size=10分页查询岗位
GET /job/major?major=计算机按专业模糊查
GET /job/salary?min=&max=按薪资区间查
