# Java 方法（Method）详解

> 配套示例：`MethodsDemo.java`。方法 = 把一段功能"打包命名"，需要时调用，避免重复写代码。

---

## 一、为什么需要方法
想象你要算 3 次"两个数相加并打印"：
```java
// 没有方法：同样的代码抄三遍，又臭又长
System.out.println(3 + 5);
System.out.println(10 + 20);
System.out.println(7 + 8);
```
用方法后：
```java
addAndPrint(3, 5);
addAndPrint(10, 20);
addAndPrint(7, 8);
```
**方法的三大好处**：① 代码不重复 ② 改一处全局生效 ③ 名字即注释（见名知意）。

## 二、方法的解剖图
```
修饰符  返回类型  方法名      (参数列表)      方法体
 ↓       ↓        ↓           ↓              ↓
static  int      add    (int x, int y) {  return x + y;  }
```
- **修饰符**：目前先写 `static`（意思是"可以直接被 main 调用"，后续学面向对象会讲实例方法）。
- **返回类型**：方法"交回"的数据类型。`void` 表示不交回任何东西。
- **方法名**：小驼峰命名，动词开头，如 `sayHello`、`calculateScore`。
- **参数列表**：调用时传给方法的"原料"，格式 `类型 名, 类型 名`。
- **方法体 `{}`**：具体做啥。
- **return**：① 把结果交回去；② 立刻结束方法。

## 三、两种方法的区别（最重要）
| 类型 | 返回类型 | 是否要 return 值 | 例子 |
|---|---|---|---|
| 无返回值 | `void` | 不需要（也可写 `return;` 提前结束） | `sayHello` 只打印 |
| 有返回值 | 具体类型(`int`/`String`…) | **必须** `return 值;` | `add` 返回计算结果 |

⚠️ 有返回值的方法，**任何分支都要保证能 return**。比如 `max` 里 if/else 两边都写了 return，否则编译报错"缺少返回语句"。

## 四、参数 vs 实参（别混）
- **参数（形参）**：方法定义里的 `int x, int y`，相当于"占位符"。
- **实参**：调用时真正传进去的值 `add(3, 5)` 里的 `3` 和 `5`。
- 传参是"按值传递"：方法里改形参，不影响外面的实参（基础类型如此）。

## 五、方法重载（Overload）
**同一个类里，方法名相同，但参数列表不同（个数或类型不同）**，Java 会自动按传入的参数匹配正确的版本。
```java
static int add(int x, int y) { ... }        // 2 个 int
static int add(int x, int y, int z) { ... } // 3 个 int → 不同方法
static double add(double x, double y) { ... } // 类型不同 → 不同方法
```
注意：**仅靠"返回类型不同"不算重载**，编译器分不清。

## 六、调用方法的本质
`main` 里写 `add(3, 5)` → 程序跳到 `add` 方法执行 → 算完 return 7 → 回到 `main` 继续。方法调用就是"暂时离开当前位置去办完一件事再回来"。

## 七、新手常踩的坑
1. **有返回值却忘写 return**，或某个分支没 return → 编译报错。
2. **参数类型/个数对不上**：`add(3)` 找不到只收一个 int 的 add → 报错。
3. **在 static 方法里直接调用非 static 方法** → 报错（后续学对象后再理解，现阶段方法都先加 `static`）。
4. **方法名乱起**：用中文或拼错，难维护和调用。

## 八、练习（动手才算学会）

2. 写一个 `static void printTriangle(int n)` 用循环打印 n 行星号（如 n=3 打印三行 * /**/***）。
3. 给 `add` 再加一个重载：接收 4 个 int 求和。
